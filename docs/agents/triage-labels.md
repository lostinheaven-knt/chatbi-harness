# Triage Labels

The engineering skills use five canonical triage roles. Local Markdown issues
record the corresponding label in their `Status:` field.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | More information is required from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment. |
| `wontfix` | `wontfix` | Will not be actioned. |
